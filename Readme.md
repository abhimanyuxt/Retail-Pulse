# RetailPulse — Retail Sales Analytics

## Project Overview
RetailPulse is an end-to-end retail sales analytics project built using Python, SQL, and Power BI. It analyzes retail transactions to understand revenue, profit, product performance, customer behavior, and regional sales trends.

## Tools & Technologies
- **Python:** Pandas, data cleaning, exploratory data analysis (EDA)
- **SQL:** MySQL, aggregations, CTEs, window functions, ranking, month-over-month analysis
- **Power BI:** DAX measures, interactive slicers, data visualization
- **GitHub:** Version control and project documentation

## Project Workflow
1. Explored and validated the retail sales dataset using Python.
2. Cleaned and transformed the data and exported a processed CSV.
3. Used MySQL to analyze revenue, profit, products, customers, regions, and monthly growth.
4. Built a Power BI dashboard with KPI measures, charts, and filters.
5. Published the project files on GitHub.

## Key Analysis
- Total revenue, cost, profit, and profit margin
- Revenue and profit by category and region
- Top-performing products and customers
- Monthly revenue trends and month-over-month growth
- Product revenue rankings using SQL window functions
- Orders by city and customer revenue-versus-profit analysis
